## 三、核心发现

### 3.1 框架链路验证通过
A_01.2（kingshot）以 SETTLED_COMPLETE 完成，**三次 clean replay + 三次 acceptance gate 全部 PASS**，产出 source capsule 与稳定策略。证明"确定性 harness + Codex 长程规划"可以端到端通关并稳定复现。

### 3.2 三大失败模式
1. **BLOCKED_UNSAFE（死亡）37%**：whiteout 尤其严重（10-55 步快速死亡），纯探索策略缺生存先验
2. **BUDGET_EXHAUSTED（预算耗尽）26%**：探索效率不足；**A_11.4 关键线索**——敌人 108/门 HP 0 但无 completion 信号，疑似判定信号缺失而非策略失败
3. **ANALYSIS_REQUIRED（语义边界）26%**：Codex 反复撞 no_progress 边界（如 unlock_cashier 卡 531 步）

### 3.3 假阳性缺陷（A_05.1）
steps:0 处被判 SETTLED_COMPLETE（零动作复用启动 CTA 候选），`initialBaselineResidualGameplayContradiction` 未拦住。已在平台 normalizer 层修复。

### 3.4 框架可靠性
- 19 任务无 harness 级崩溃；安全监视器（player_dead/lose_panel 检测）、预算控制、审计链、gate 全链路可靠
- 渲染稳定：全部 58-59 FPS（NVIDIA L4），0 context loss / shader / screenshot errors
